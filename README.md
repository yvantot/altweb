# AltWeb

Alt-Tab for the browser: switch between tabs, windows and bookmarks without leaving the page you're on.

## Shortcuts

| Shortcut | Action |
| --- | --- |
| Alt + W | Open AltWeb and move forward |
| Alt + Q | Open AltWeb and move backward |
| Alt + E | Search your tabs |
| Alt + D | Close the selected tab |

You can change these at `chrome://extensions/shortcuts`.

## Install

1. Download or clone this repository.
2. Open `chrome://extensions` and turn on **Developer mode**.
3. Click **Load unpacked** and choose this folder.

## Built with

JavaScript and the Chrome Extensions API (tabs, windows and bookmarks, Manifest V3).
